# Full-Stack Web Application for Managing Employees
## Supervisor
Vasilios Kelefouras
## Vision
For the employer that wants an easier time managing their employees, and the employees that want a more seamless experience with their work. Timetabling and scheduling is an essential part of the workplace as it informs people when and where they’re supposed to be. If it is done wrong, employees may be absent or uncompensated. My project is a full stack web app that will allow a business to distribute work schedules, as well as track when employees are clocked in.
## Getting started
1. Clone the repository:
`git clone https://github.com/Meemog/OscarThomsonComp3000.git`
2. Install [Docker](https://docs.docker.com/get-started/get-docker/)
3. Ensure the docker service is running on your system before running `docker compose up -d` in the `src` directory

This will create a development environment of the system running on http://localhost:80
