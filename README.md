# Full-Stack Web Application for Learning Sheet Music (“SeeSharp”) 
## Supervisor
Vasilios Kelefouras
## Vision
For aspiring musicians that want to learn how to sightread sheet music. Sightreading is the ability to look at a piece of sheet music and know how to play it with limited processing time. It is an important skill for musicians to have as it allows them to play music with a band without having rehearsed it beforehand. SeeSharp is a full stack web app that will show users sheet music and then play a metronome. The users would then play along with an actual instrument, using their computer’s microphone, and the app would show if they played the correct notes.
